# 📌 Project Overview & Journey

Understanding fiscal policies can be complex. "موازنتك" transforms national budget figures into an interactive learning experience through a seamless 5-step flow:

1. Homepage Assessment: An introductory survey that evaluates user awareness and introduces core budget concepts.
2. Interactive 5-Sector Wheel: A custom JavaScript wheel featuring Education, Health, Revenues, Social Protection, and Public Debt.
3. Sector-Specific Quizzes: Dynamic multiple-choice quizzes tailored to each selected sector.
4. Instant Visual Feedback: Real-time answer validation with educational explanations.
5. Score & QR Integration: Final score breakdown with a QR code linking to official financial documents and resources.

---

# ✨ Key Features

* 📝 Onboarding Survey: Introductory form on the homepage to set context.
* 🎡 Custom Wheel Logic: Smooth JavaScript algorithm for budget sector selection.
* 🧠 Dynamic Quiz Engine: Sector-tailored questions with automated scoring.
* 💡 Instant Answer Explanations: Green/red visual indicators with educational notes.
* 📲 QR Code Support: Quick access to official Ministry of Finance resources.
* 📱 Responsive Design: Fully optimized Arabic-first UI for mobile and desktop.
